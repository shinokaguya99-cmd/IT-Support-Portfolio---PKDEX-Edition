# Pokémon-Inspired IT Portfolio

A responsive React + Vite portfolio starter with a red/blue Pokémon-game-inspired interface.

## Requirements
- Node.js 18 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Create a production build

```bash
npm run build
npm run preview
```

## Personalize it

Open `src/App.jsx` and replace:
- `[Your Name]` with your preferred display name
- `your.email@example.com` with your email address
- Sample project descriptions with your real projects
- Skill ratings with honest estimates of your current abilities
- Social links with your own GitHub and LinkedIn URLs

The avatar and Poké Ball graphics are CSS-based placeholders, so the project works without image assets.

## Main files
- `src/App.jsx` — page content and React components
- `src/styles.css` — responsive styling and theme
- `src/main.jsx` — React entry point
- `index.html` — page metadata and title
